# ADR-0021：任务填报项的 AI 文本候选

日期：2026-09-28

## 决策

Collector 可在任务填报或审核期间，对当前模板的占位符输入提示词，使用服务端 Vercel AI SDK OpenAI-compatible provider 生成纯文本候选。Web 仅提供任务名、报告月份、占位符上下文和至多十条最新提交值作为输入快照，并在 `AiGeneration` 中保存提示词、输入、模型与原始输出。候选先进入可编辑的人工值字段，不直接写 FinalValue 或 PPT。

用户修改并保存人工最终值时，若关联候选 ID 属于该任务、该占位符及当前 Collector，则同一事务写入 `acceptedText` 和采纳日志。未配置 AI 或调用失败不会改变任务状态，也不阻断原有人工、指标及提交值流程。

## 影响

沿用现有 `AiGeneration` 和 `OperationLog` 表，无数据库迁移。最终值仍使用 `MANUAL` 决策类型，AI 只解释候选的来源，不扩展最终值类型。输入快照含业务文本，应继续按任务权限保护数据库与备份；操作日志不重复记录文本正文。
