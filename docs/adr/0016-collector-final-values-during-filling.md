# ADR-0016：收集人在填报阶段填写最终值

- 日期：2026-09-23
- 状态：接受

## 背景

收集人可能需要在填报人尚未全部提交时，自行填写模板页面的指标或人工值。原有 FinalValue 只能在 `REVIEWING` 阶段确定。

## 决策

1. `FILLING` 与 `REVIEWING` 阶段均允许任务 Collector 保存 `MANUAL` 或 `DATABASE_METRIC` FinalValue。指标由服务端按指定月份重新读取并冻结文本及来源快照，不信任浏览器传入的指标值。
2. `SELECTED_SUBMISSION` 仍仅在 `REVIEWING` 阶段可用，且只能选当前提交 revision。所有最终值写入继续使用 ReportTask 版本条件、同库事务和操作日志。
3. Collector 早期填写的值在填报人提交时保留，提交不会自动覆盖 Collector 的明确决定；审核时可改用提交值。退回某个填报实例仍按 ADR-0011 清除该页全部 FinalValue，要求重新确认。
4. 完成审核仍要求所有填报实例提交、模板所有占位符有最终值，生成服务继续只读取 FinalValue。

## 后果

- 填报中的页面可能同时显示 Collector 的最终值和等待中的填报实例，页面标识为“收集人已填”，但任务仍须走完提交及审核流程。
- 指标值采用保存时的快照；源库以后变更不会静默改变已经确认的报告值。
