# ADR-0020：样例 PPT 经 AI 候选和人工确认生成模板

日期：2026-09-28

## 背景

现有模板必须预先写入 `{{key}}`。收集人也会持有已填写真实数据的样例 PPTX，希望从其中识别可变值并生成可复用模板。模型判断可能遗漏、误选固定文字或返回不存在的文本，不能直接写入正式模板。

## 决策

1. 仅 Collector 可调用 `POST /api/templates/from-sample`。`action=generate` 接收样例 PPTX 和可编辑提示词；Web 将临时文件放在共享存储，PPT Service 按页、Shape、表格单元格和段落提取文本；Web 使用 Vercel AI SDK 的 OpenAI-compatible provider 请求候选子串及 key。`AI_PROVIDER`、`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` 均从服务端配置读取，未配置时仅该 AI 功能不可用。
2. 返回的候选仅供浏览器展示，用户可改原文、改 key、删除或新增候选。用户可先按当前清单下载待确认 PPTX，打开检查后调整并重复下载；正式上传须再次提交同一文件及确认后的清单。Web 验证 SHA-256、段落身份、原文唯一性、重叠范围和 key 语法；PPT Service 再次验证文件哈希和替换范围，在 TextRun 上就地替换为 `{{key}}`。原样例文件不修改。
3. 生成的 PPTX 再进入现有模板上传、POI 解析、预览和状态持久化链路。操作日志只保存文件哈希、模型名称、提示词哈希和数量，不写入样例文本、密钥或完整提示词。临时样例文件在成功或失败后清理。
4. AI 结果不会写入任务 FinalValue。已有任务值的 AI 候选能力仍属于 P7 后续工作；本决策只覆盖从样例生成模板和 provider 接入。

## 影响

模板本身仍以 PPTX 和解析元数据为唯一正式来源，不新增模板草稿表或迁移。候选只存在于当前浏览器会话；刷新页面需重新生成。PPT Service 新增内部接口，但不访问模型、数据库或用户身份。最终样式沿用原始 TextRun；跨 Run 替换会把占位符文字放在起始 Run 中。当前支持可提取的文本框与表格单元格，不识别图片中的文字。
