# ADR-0022：平台手动指标

日期：2026-09-28

## 背景

指标管理原先只读取已配置外部数据源的指标。收集人需要录入不在外部库中的月度指标，并供填报绑定、审核最终值使用。

## 决策

1. 在 `DataSourceType` 中增加 `MANUAL`，使用固定 ID `manual-metrics` 的平台内置来源。此来源不配置数据库连接，也不出现在外部数据源管理列表。
2. 手动指标仍使用 `MetricDefinition`、`MetricValue`、`MetricValueHistory`。定义在各月复用；空维度摘要与现有镜像一致。创建指标或追加月份值时，在平台数据库事务中写入值、历史和操作日志。相同编码仅在名称、类型、单位一致且目标月份无值时追加月份。
3. 手动指标读取、月份查询、目录分页、填报绑定快照和审核最终值均从平台库读取。已创建的值可按版本条件修改并记录原因；无值月份以预期版本 0 补录。手动指标没有外部源，因此不执行对账。
4. Collector 才能创建、修改和查看指标管理历史。填报实例继续沿用原有实例权限读取月度指标。外部数据源的查询、修改和对账流程不变。

## 影响

迁移扩展 `DataSource.type` 枚举；部署新版本前需执行 Prisma migration。手动值与外部源值共用指标选择列表，但来源名称标明“手动录入”。已绑定的快照保持原值；后续修改不会悄悄覆盖既有填报绑定。
