# ADR-0008：P4 指标源连接与凭据边界

- 日期：2026-09-21
- 状态：接受

## 背景

系统 MySQL 保存任务、绑定与快照；指标 MySQL 是独立、由 Collector 配置的外部数据源。企业内网可能没有 HTTPS，但数据源密码仍不能以明文进入系统库、API 响应或日志。

## 决策

1. P4 首个垂直切片仅支持 `MYSQL` 类型。Collector 可创建配置、查看无密码的列表并执行连接测试；Filler 无权调用。指标映射与读写在后续切片实现。
2. 密码使用 `ENCRYPTION_KEY` 指定的 32 字节密钥、随机 96 位 nonce 的 AES-256-GCM 加密。密文、认证标签和 nonce 存在 `DataSource.encryptedPassword`，`encryptionKeyVersion` 单独存储。密钥只由部署环境注入，不写入数据库、API 或审计。
3. 当前仅支持当前版本密钥解密。轮换前须先保留旧密钥、迁移所有密文，再切换部署密钥；后续扩展多版本 keyring。密钥缺失或版本不匹配时服务拒绝操作，不降级为明文。
4. MySQL Adapter 与系统 Prisma Client 分离，使用独立连接、5 秒连接超时、`SELECT 1` 探测，并关闭连接。连接异常对浏览器统一返回 `DATASOURCE_UNAVAILABLE`，不泄露驱动错误或凭据。连接测试成功/失败均记录不含密码的审计事件。
5. 数据源 `ACTIVE` 表示配置启用，不代表实时连接健康；连接测试响应单独表达本次探测结果。外部数据库不由默认 Compose 托管，运行时只需内网可达。

## 后果

- 当前连接测试是最小探测，不保证后续表/查询权限；下一切片应按可配置、受限的指标映射验证查询，禁止任意 SQL 输入。
- 无 HTTPS 内网 HTTP 登录和数据源配置请求仍以明文在浏览器与 Web 之间传输，必须依赖受控内网、主机防火墙与代理访问控制；应用层加密仅保护数据库静态凭据。
