# ADR-0015：模板列表按需加载与删除归档

- 日期：2026-09-23
- 状态：接受

## 背景

模板管理页原先一次读取并展示所有模板的全部页面、占位符和预览。模板数量增多时，列表过长，初始查询和页面内容也随总页数增长。模板可能已被任务、填报记录和生成文件引用，不能为了从列表移除而破坏这些历史数据。

## 决策

1. 模板列表只查询名称、版本、解析状态、原文件名、页数和关联任务数；默认不展开页面。用户选择某个模板后，通过受权详情接口加载其页面和占位符，渲染预览。
2. “删除模板”使用现有 `ReportTemplate.status = ARCHIVED` 状态，并写操作日志。仅创建该模板的 Collector 可操作；解析中的模板不可删除。归档后从模板列表和新任务选择中消失。
3. 保留模板、页面、源文件和预览文件元数据及实体文件。已有任务和相关成员继续按原有资源授权读取模板预览和生成报告。归档模板再次上传时仍按历史版本号递增。

## 后果

- 删除是从可用模板目录移除，不回收文件空间。若以后需要物理清理，应单独设计无引用检查、保留期和文件清理补偿。
- 展开某个模板需要一次详情请求；列表首次加载不再随模板总页数读取所有页面。
