# ADR-0007：凭据登录改用用户名

- 状态：Accepted
- 日期：2026-09-21
- 修订：登录标识已由 ADR-0014 改为 6 位工号；username 保留为人员名称。

## 背景

内网账号不一定有邮箱，用户要求直接使用用户名和密码登录。原有 `User.email` 必填、唯一，Auth.js Credentials 也只接受邮箱。

## 决策

- `User.username` 成为非空唯一登录标识；输入去首尾空格并转小写，不要求邮箱格式。`email` 改为可选，保留填写时唯一的约束及未来通知/SSO 映射用途。
- 迁移把现有用户的唯一 email 原值回填为 username，不删除用户、角色、模板或任务数据。新账号无须伪造邮箱。
- Auth.js 表单、凭据查询、种子脚本及任务分配展示均使用 username。无公开注册；运维通过 `seed:auth` 创建账号。
- 默认账号密码预置仍要求至少 12 位。仅针对隔离测试环境，显式 `AUTH_SEED_ALLOW_WEAK_PASSWORD=1` 才允许 6 位；这一开关不改变密码哈希和登录锁定机制，也不应在生产环境使用。

本 ADR 只修订 ADR-0003 的邮箱登录决定。会话授权仍基于 User ID、实时状态和角色。
