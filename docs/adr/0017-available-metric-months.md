# ADR-0017：指标查询的可用月份日历

- 日期：2026-09-23
- 状态：接受

## 背景

指标管理、填报和审核页原先让用户直接输入或使用浏览器月份输入框，无法判断某月是否有指标，空月份只能在查询后发现。

## 决策

1. 三处指标检索共用只选择到月的日历。按年读取可用月份，源库没有指标的月份置灰且不能选择；源库不可用时显示错误和重试入口，不开放未知月份。
2. 由 Web 端先做 Collector 或 FillInstance 资源授权，再读取启用数据源下已配置的指标映射。MySQL Adapter 用参数化条件按年查询源库 `metric_record` 的去重月份，Web 合并多个映射和数据源的结果。
3. 报告任务的 `reportPeriod` 改为月份选择控件，但不受指标月份限制，允许纯人工填报任务。

## 后果

- 日历展示的是查询时源库的可用月份；数据随后被删除时，实际指标查询及绑定仍由服务端再次验证。
- 新的数据源 Adapter 应实现相同的可用月份接口，不需要改变任务或指标实体结构。
