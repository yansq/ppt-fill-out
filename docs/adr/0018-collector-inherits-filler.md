# ADR-0018：收集人继承填报权限

- 状态：Accepted
- 日期：2026-09-23

## 背景

同一收集人可能需要为自己负责的报告填写页面。此前候选人员查询、分配保存校验和填报接口均只接受显式 `FILLER` 角色，因此只有 `COLLECTOR` 角色的收集人不能被分配，也不能完成填报。

## 决策

- 活跃用户具备 `COLLECTOR` 角色时，服务端将 `FILLER` 作为其有效权限；数据库中的 `UserRole` 不自动增写一条角色关系。`FILLER` 不继承收集人权限。
- 可分配人员查询和保存校验均接受活跃的 `FILLER` 或 `COLLECTOR` 用户。历史分配的展示与移除规则不变。
- 填报实例的查看、编辑、提交仍要求当前用户是该实例的 `assigneeId`；收集人对自己任务下其他人的填报实例仍只有原有查看权限。

## 结果

收集人可在分配页面选择自己或其他收集人，并通过“我的填报”完成被分配页面。权限每次从数据库角色实时计算，不依赖旧会话或一次性数据迁移。
